2026 블프 CS 답변 템플릿

11.16 (월) 오전 11:00 – 11.26 (목) 오전 11:00 자사몰

고객 문의를 찾아서 복사 버튼을 누르면 답변이 그대로 복사돼요. 여기에 없는 문의나 애매한 건은 바로 처리하지 말고 CS방에 올려주세요.

01쿠폰

1-1쿠폰이 안 떠요 / 적용이 안 돼요

확인 순서 ① 로그인(회원) 상태 ② 쿠폰 다운로드 여부 ③ 최소 주문금액 이상인지 ④ 다른 쿠폰을 이미 적용했는지

답변

안녕하세요 고객님, 더제이수입니다. 블프 쿠폰팩은 회원 전용 쿠폰이라 로그인 후 쿠폰팩 페이지에서 먼저 다운로드해 주셔야 결제 화면에 나타나요. 쿠폰별로 15만 원 / 30만 원 / 50만 원 이상 주문 시 사용 가능하고, 주문 1건에 1장만 적용됩니다. 다운로드 후에도 적용이 안 되시면 주문하실 상품과 금액을 알려주세요. 바로 확인해 드릴게요.

1-2쿠폰 2장 같이 쓸 수 있어요? / 주문을 나누면요?

답변

블프 쿠폰은 주문 1건에 1장만 사용 가능해서 2장을 한 주문에 함께 적용하실 수는 없어요. 쿠폰은 종류별로 1인 1회씩 다운로드되기 때문에, 같은 쿠폰을 여러 주문에 나눠 쓰실 수는 없습니다. 한 번에 주문하시면 더 높은 단계 쿠폰을 받으실 수 있어 혜택이 더 커요.

내부 참고: 세팅상 7,000원 쿠폰과 18,000원 쿠폰을 서로 다른 주문에 각각 쓰는 건 가능해요. 고객이 직접 물어보면 "서로 다른 쿠폰은 각각 다른 주문에 사용 가능"이라고 안내하세요.

1-3주문 취소하면 쿠폰 돌려받나요?

기준: 주문 취소 시 복원, 반품 시 복원 안 됨

답변

주문을 취소하시면 사용하신 쿠폰은 다시 복원돼요. 블프 기간(11.26 오전 11시까지) 안에 다시 주문하실 때 사용하실 수 있습니다. 다만 상품을 받으신 뒤 반품하시는 경우에는 쿠폰이 복원되지 않아요.

1-4쿠폰 다운로드는 어디서 해요?

답변

메인 화면 블프 배너나 상품 상세페이지 구매하기 버튼 상단의 띠배너를 누르시면 쿠폰팩 다운로드 페이지로 바로 이동해요. (다운로드 기간: 11.16 오전 11시 ~ 11.26 오전 11시)

1-5특가(라스트피스·세일) 상품에도 쿠폰 돼요?

답변

네, 이번 블프 쿠폰은 특가 상품을 포함한 전 상품에 사용 가능해요.

02적립금

2-1적립금 왜 못 써요?

답변

블프 기간(11.16 오전 11시 ~ 11.26 오전 11시)에는 할인과 쿠폰팩 혜택을 크게 드리는 대신 적립금 사용이 잠시 제한돼요. 보유하신 적립금은 그대로 남아 있고, 11.26 오전 11시 이후부터 다시 사용하실 수 있어요.

03사은품

3-1사은품 기준 금액이 쿠폰 쓰기 전이에요, 후예요?

답변

사은품은 쿠폰 사용 전 주문서에 뜨는 결제금액 기준이에요. 30만 원 이상 주문 시 집게핀, 50만 원 이상 주문 시 집게핀과 라쿤 니트(선착순 30명)를 함께 보내드려요. 쿠폰을 사용하셔도 사은품은 그대로 받으실 수 있어요.

3-2니트 선착순 마감됐어요? 저도 받을 수 있어요?

확인 니트 지급 현황(결제 완료 순서)을 보고 남은 수량을 안내하세요.

남아 있을 때

현재 라쿤 니트는 ○개 남아 있어요. 결제 완료 순서대로 증정되니 참고 부탁드려요.

마감됐을 때

아쉽게도 라쿤 니트 선착순 30명은 마감되었어요. 50만 원 이상 주문 시 집게핀은 계속 함께 보내드려요.

3-3니트 컬러 고를 수 있어요?

답변

라쿤 니트는 사은품이라 컬러는 랜덤으로 발송되고 선택이 어려워요. 사이즈는 프리사이즈예요. 양해 부탁드려요.

3-4반품하면 사은품도 보내야 해요?

기준: 반품 후 남은 금액이 사은품 기준 아래로 내려가면 해당 사은품을 함께 반납 (집게핀 30만 원 · 니트 50만 원)

집게핀 · 반품 후 30만 원 이상 유지

반품 후에도 남은 주문금액이 30만 원 이상이시면 집게핀은 따로 보내주지 않으셔도 괜찮아요.

집게핀 · 반품 후 30만 원 미만

반품 후 남은 주문금액이 30만 원 미만이 되면 사은품 집게핀도 반품 상품과 함께 보내주셔야 해요. 집게핀을 보내주지 않으시는 경우에는 집게핀 정가 금액을 결제하시거나 환불 금액에서 차감됩니다.

라쿤 니트는 아래 4-2 기준에 맞춰 안내하세요.

04반품·교환

4-1반품하고 다시 주문하는데 쿠폰 또 쓸 수 있어요?

답변

상품을 받으신 뒤 반품하시는 경우, 사용하신 쿠폰은 복원되지 않아 다시 사용하실 수 없어요(쿠폰은 종류별 1인 1회). 다른 단계의 쿠폰을 아직 사용하지 않으셨다면 그 쿠폰은 새 주문에 사용 가능해요.

함께 안내 (부분 반품)

부분 반품 후 남은 주문금액이 쿠폰 최소 주문금액보다 적어지면, 쿠폰 할인액을 차감하고 환불돼요.

4-2반품해서 50만 원 미만이 되면 니트는요?

기준: 부분 반품으로 50만 원 미만이 되거나 전체 반품하면 니트 반납

부분 반품 · 50만 원 미만

일부 상품 반품 후 남은 주문금액이 50만 원 미만이 되면 사은품 라쿤 니트도 착용하지 않은 상태로 반품 상품과 함께 보내주셔야 해요.

전체 반품

주문 상품을 전부 반품하시는 경우에는 사은품(집게핀, 라쿤 니트)도 착용하지 않은 상태로 함께 보내주셔야 해요.

찾는 답변이 없어요. CS방에 문의해 주세요.
